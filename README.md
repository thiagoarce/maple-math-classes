# Maple Math Classes

Biblioteca em construção de recursos pedagógicos de matemática, empreendedorismo e olimpíadas, ferramentas de sala de aula e sistemas de produção de materiais.

O objetivo é preservar e aperfeiçoar práticas docentes reutilizáveis: explicação matemática, investigação, prática deliberada, representações visuais e recursos interativos.

## Disciplinas

- [Matemática HS](subjects/hs-mathematics/README.md)
- [Entrepreneurship](subjects/entrepreneurship/README.md)
- [Olimpíadas](subjects/olympiads/README.md)

Cada frente possui organização curricular e pedagógica própria. A infraestrutura é compartilhada, e turmas reais, matrículas e planejamento operacional ficam em ambiente privado.

## Organização prevista

| Diretório | Finalidade |
|---|---|
| `subjects/` | Currículos, materiais autorais e guias por disciplina, nível e unidade |
| `materials/` | Acervo transversal, quando um recurso não pertence exclusivamente a uma disciplina |
| `templates/` | Modelos de handouts, listas e slides |
| `tools/` | Geradores matemáticos, produção e validação |
| `apps/` | Aplicações independentes de sala de aula |
| `assets/` | Recursos visuais com direitos de publicação verificados |
| `tests/` | Testes e dados fictícios |

As três frentes já têm índices documentais; subpastas de conteúdo são criadas quando houver recursos revisados. Não há aplicação instalável nem serviço de produção nesta etapa.

## Privacidade e direitos

Este repositório é público. Dados escolares reais e arquivos personalizados não devem entrar em nenhum commit, branch, issue, PR ou artefato. Consulte a política de publicação antes de contribuir.

A visibilidade pública não equivale a licença geral de redistribuição. A licença dos componentes autorais e a autorização para uso de identidade institucional ainda devem ser definidas. Dependências de terceiros conservam suas respectivas licenças.
