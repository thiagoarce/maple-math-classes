# Reserva de água — protótipo de volumetria

Atividade existente reaproveitada como exemplo independente, com adaptação de dois rótulos de identidade. O HTML, CSS e JavaScript funcional permanecem como na origem revisada. Não inclui recursos externos, persistência, cadastro ou comunicação com servidor.

Abra index.html em um navegador local. A atividade permite girar um prisma retangular, alterar comprimento, largura, altura e preenchimento, visualizar a seção horizontal, conferir área e volume, resolver um problema de otimização e transferir o raciocínio a outro contexto.

## Revisão

- Inspeção estática do HTML e JavaScript: nenhum asset externo ou acesso a dados privados encontrado.
- Conferência matemática independente: capacidade inicial 96 L, água inicial 48 L, menor altura 6 dm com base 16 dm², área de transferência 4 m².
- O desenho em canvas é ilustrativo e a paleta é provisória.
- A previsão inicial é um convite textual, não uma etapa obrigatória registrada antes da experimentação.
- Teste interativo no navegador, acessibilidade e revisão pedagógica docente ainda pendentes. Não apresentar como recurso homologado nem como motor final.
